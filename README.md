# Osteria da Massimo — Website Relaunch

Performance-orientierte statische Website für die Osteria da Massimo in München.

## Zielbild
- zweisprachig Deutsch / Italienisch
- Local SEO mit klaren Suchintentionen
- statisches HTML, minimales JavaScript
- mobile Reservierungswege
- Restaurant Structured Data
- Sitemap, robots.txt, Canonicals und hreflang
- eigene Landingpages für Veranstaltungen, Westfriedhof und Live-Musik

## Vercel
Zero-build Static Deployment. `vercel.json` aktiviert Clean URLs und Security Header.

## Vor dem Produktivgang verifizieren
1. Öffnungszeiten: aktuell wurden die Angaben der bestehenden Website (täglich 11:30–23:00 Uhr) übernommen
2. Bildassets: aktuelle Restaurantfotos werden für die Preview noch von der bestehenden Website geladen und müssen vor DNS-Umschaltung lokal in dieses Repository übernommen werden
3. Speisekarten-PDFs: vor DNS-Umschaltung lokal übernehmen oder durch final gepflegte HTML-Menüs ersetzen
4. Datenschutz: final an den tatsächlich gebuchten Vercel-Tarif, AV-Vertrag und die Produktionskonfiguration anpassen und rechtlich prüfen
5. Live-Musik: die acht konkreten Termine Oktober 2026 bis Mai 2027 ergänzen, sobald bestätigt
